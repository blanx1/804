# 8.04 Practice Site

Open `index.html` in a browser (internet needed for MathJax and marked). Progress is saved in that browser.

- Edit content in `tools/content/`, then run `py tools/build.py` (needs numpy and scipy for the figures).
- `tools/verify_physics.py` numerically checks the riskiest answer keys.
- To publish on GitHub Pages, push this folder as a repository and enable Pages. `content.js` must be included.

Questions and lessons are original study material based on the course's topics; they are not official 8.04 materials.
Engine and styles adapted from the 6.200 practice site, which runs on CAT-SOOP (AGPLv3).
